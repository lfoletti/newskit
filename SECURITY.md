# Politique de sécurité

## Signaler une faille

N'ouvrez pas d'issue publique pour une faille. Utilisez le signalement privé de GitHub : **Security**, puis **Report a vulnerability**, sur ce dépôt.

Donnez la version ou le commit, les étapes qui montrent la faille et ce qu'un attaquant peut en faire. Vous recevez une réponse sous 7 jours.

## Ce qui compte

Newskit lit des pages et des flux du web, puis les passe à un modèle. Comptent en particulier :

- une source qui fait exécuter une consigne au modèle (injection) ou écrire hors du dossier du média ;
- une garde contournée : le plafond de dépense, la marque de limite, le témoin ;
- une clé ou une donnée privée écrite dans un journal, une fiche ou un message d'erreur.

## Versions suivies

Seule la dernière version publiée et la tête de `main` reçoivent des correctifs.
